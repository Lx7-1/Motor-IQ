# PRODUCT

Build a modern marketplace called

# IQ Motor

A marketplace dedicated to motorcycles, bikes, scooters, ATVs, and similar vehicles across Iraq.

The platform allows:

* Individual sellers
* Dealers
* Buyers

to buy and sell vehicles in an easy, modern, secure way.

The long-term vision is to become Iraq's largest vehicle marketplace.

The MVP focuses on motorcycles and bikes first, with the architecture designed so cars, trucks, boats, agricultural equipment, and other vehicle types can be added later without requiring database redesign.

# CODING STANDARDS

* Use strict TypeScript.
* Avoid `any`.
* Write clean, modular, documented code.
* Validate all forms with Zod.
* Handle loading, empty, and error states.
* Use reusable UI components.
* Add comments only where they improve maintainability.
* Prefer composition over duplication.

# SUCCESS CRITERIA

The MVP should:

* Feel like a polished commercial marketplace, not a prototype.
* Be fully responsive and fast on mobile networks.
* Allow buyers, sellers, and dealers to complete core tasks end-to-end.
* Be easy to extend with additional vehicle categories, payment systems, and premium features.
* Be production-ready, secure, and maintainable.

Begin with **Phase 1 only**, explain the architecture decisions briefly, generate the initial project structure, and **wait for approval before proceeding to the next phase**. This aligns with the product vision and MVP requirements you defined for IQ Motor.
