# Motor-IQ
Automatic License Plate Recognition (ALPR) system built with Python, OpenCV, and YOLO.⁠
## Overview
Motor-IQ is an end-to-end Automatic License Plate Recognition (ALPR) solution designed for real-time vehicle identification and plate detection. Built using computer vision techniques and deep learning models, it streamlines license plate extraction and character recognition for surveillance and traffic monitoring systems.

## Features
* **Vehicle & Plate Detection:** Powered by custom-trained YOLO models for high accuracy.
* **Image Processing:** OpenCV pipelines for frame extraction, contrast enhancement, and noise reduction.
* **Character Recognition:** Efficient extraction of alphanumeric characters from detected license plates.
* **Real-time Pipeline:** Designed to process video streams and static image inputs.

## Tech Stack
* **Language:** Python
* **Computer Vision:** OpenCV
* **Deep Learning Framework:** YOLO (You Only Look Once)
* **Data Processing:** NumPy, Pandas
